# Bitácora de propuestas de mejora

Cada archivo `YYYY-MM-DD-titulo.md` en esta carpeta es una propuesta de
cambio a la estrategia o al sistema, con este formato:

- **Hipótesis**: qué se cree que va a mejorar y por qué.
- **Respaldo**: fuente (paper, resultado observado en paper trading, etc.).
- **Cambio propuesto**: diff conceptual concreto.
- **Resultado del walk-forward**: métricas antes/después.
- **Decisión**: aprobado / rechazado / pendiente (la decide el usuario).

Ninguna propuesta se aplica al código de `strategy/`, `risk/` o `execution/`
sin que su estado sea "aprobado".
